# 威胁建模

SMS Bridge 会处理一次性验证码（OTP）。验证码是高价值鉴权材料；本文件说明开源版本的安全假设与边界，不代表被入侵的 Mac、Telegram 账户或 Apple 账户仍能被本工具保护。

## 资产

| 资产 | 风险 | 设计保护 |
| --- | --- | --- |
| macOS 信息数据库 | 可能含有全部已同步对话 | 用户显式授予完全磁盘访问权限；SQLite `mode=ro` 只读查询；不上传副本 |
| Telegram Bot Token | 可读取机器人更新、代表机器人发消息 | 静态存于 macOS Keychain；运行时单次读入进程内存；不渲染、不写日志、不进入 plist |
| 验证码与发件人标识 | 可授权账户或暴露服务关系 | 仅内存处理；为可用性发送发件人；不保存 relay 历史 |
| 配对链接 | 可绑定接收聊天 | 256-bit 随机值；只保存 SHA-256 哈希；十分钟；单次使用 |
| 已配对 Chat ID | 决定验证码接收方 | 仅当前用户可访问的本地 SQLite；仅一个私聊 |

## 信任边界

1. **macOS 与本地用户账户**：项目依赖该账户和其完全磁盘访问策略。同一账户下的恶意软件可能读取信息数据库或 relay 状态，这超出本工具可解决的边界。
2. **Apple 信息同步**：程序只能处理已经同步到 Mac 的内容；它不会绕过 iOS 沙箱或 Apple 账户安全。
3. **Telegram**：Telegram Bot API 是唯一预期的出站网络目标。发送验证码即代表验证码会被 Telegram 基础设施和已配对 Telegram 账户处理。
4. **本机设置页**：设置页仅绑定 `127.0.0.1`、拒绝跨站写请求、只接收 JSON 并限制请求大小。不得通过隧道、反向代理、端口转发或浏览器共享工具暴露它。

## 威胁与控制

| 威胁 | 控制 | 剩余风险 |
| --- | --- | --- |
| 配对 URL 被复制或猜到 | 256-bit 熵、哈希存储、单次使用、短期过期、私聊校验 | URL 在有效期内泄露仍可能被先使用；必须把它当作凭据 |
| Bot Token 泄露 | Keychain、secret 扫描、无日志；文档化轮换 | Token 在 @BotFather 撤销前仍有权限 |
| 恶意网页向 localhost 发 POST | Origin/Content-Type 校验、回环绑定、大小限制 | 被入侵的本地浏览器扩展可能拥有用户浏览器权限 |
| 完全磁盘访问授权范围过大 | 双击启动器创建仅当前用户可用的专用 Python 运行时，并只建议为它授权 | 任何被主动交给该专用解释器执行的代码仍会继承权限 |
| 用户启用“所有收到的文本” | 默认关闭；界面在启用前明确警告；仍只发送到单一已配对私聊 | 普通短信与 iMessage 原文会经过 Telegram 基础设施 |
| 多进程重复转发 | `flock` 单实例锁 | 同一用户下的恶意进程可忽略用户级锁 |
| Telegram 临时故障 | 有界重试、指数退避；通知成功后才提交游标 | 投递会延迟；本工具不是保证投递系统 |
| 全文短信泄露 | 默认发送服务名、验证码和发件人；全文必须由用户显式开启 | 发送到 Telegram 的验证码和发件人仍然敏感 |
| 规则误匹配 | 关键词 + 4–8 位数字 | 仍可能误报；后续应加入发送者白名单 |

## 明确非目标

- 不提供用户选择的第三方平台之外的端到端加密；
- 不支持多用户、群组或公开投递；
- 不做云端备份、网页历史或短信归档；
- 不处理越狱 iPhone 或绕过 Apple 权限；
- 不宣称验证码转发适合所有金融、医疗或企业账户。

## 发布门槛

每次发布前必须运行测试与 secret 扫描；确认 Git 跟踪内容和发行包中没有 `.env`、状态数据库、日志、配对 URL、验证码、Chat ID 或 Bot Token；复审配对、Keychain、本机 HTTP 和通知渲染的修改；并在干净 macOS 用户账户中测试 `doctor`、`pair`、`test`、`unpair` 与 `uninstall`。
